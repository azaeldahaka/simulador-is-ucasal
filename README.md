# Simulador 2do Parcial Teórico — Ingeniería de Software (UCASAL)

Simulador interactivo mobile-first con:
- 80 preguntas de Múltiple Choice con trampas conceptuales y barajado aleatorio.
- 14 esquemas gráficos SVG interactivos para rotular.
- 6 matrices de verificación de conceptos (10 casillas).
- Modo Examen Real (10 ejercicios aleatorios, 20 min, calificación estricta 60/100).
- Modo Práctica libre con filtros y Radar Cazabobos.
- Hoja de trucos (Cheat-Sheet) de repaso rápido.
